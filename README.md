# Local agent work tracker

Discovery project for a Docker-hosted task tracker with a local MCP endpoint and a human review interface.

The first pass is in [Jira capability research](docs/JIRA_RESEARCH.md) and [candidate product requirements](docs/REQUIREMENTS_DRAFT.md). UI/UX design: [UI design proposal](docs/UI_DESIGN.md) with a clickable [prototype](design/prototype.html). These are discovery artifacts, not an approved implementation specification.

Current phase: research and requirements. MVP V1 can be built and verified with disposable sample work; a real pilot project will be selected afterward. No container or MCP server has been implemented yet.
