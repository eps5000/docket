# Local agent work tracker

Discovery project for a Docker-hosted task tracker with a local MCP endpoint and a human review interface.

The first pass is in [Jira capability research](docs/JIRA_RESEARCH.md) and [candidate product requirements](docs/REQUIREMENTS_DRAFT.md). UI/UX design: [UI design proposal](docs/UI_DESIGN.md) with a clickable [prototype](design/prototype.html). Current phase: **ready to build V1.** Start with the [build spec](docs/BUILD_SPEC.md) (architecture, data model, rules, MCP tools, API, milestones, decisions) and the [UI spec](docs/UI_SPEC.md) (screens, components, tokens, states, accessibility). The [prototype](design/prototype.html) is the visual reference, and [sample-data.json](design/sample-data.json) is the seed data. Requirements, design rationale and research are background: [requirements](docs/REQUIREMENTS_DRAFT.md), [UI design](docs/UI_DESIGN.md), [Jira research](docs/JIRA_RESEARCH.md).

No container or MCP server has been implemented yet. MVP V1 is built and verified with disposable sample work; a real pilot project is selected afterward.
